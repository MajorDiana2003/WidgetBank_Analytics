# WidgetBank Analytics — Приложение для анализа банковских транзакций

Программа представляет собой аналитический инструмент для обработки истории финансовых операций пользователя. Приложение агрегирует данные из Excel-выписок, интегрируется с внешними финансовыми API Центробанка РФ и Yahoo Finance для получения актуальных котировок, предоставляет интеллектуальные сервисы поиска и автоматически генерирует кастомные отчеты в формате Excel.

## 🛠️ Стек технологий
* **Язык разработки:** Python 3.11+
* **Анализ данных:** Pandas, Openpyxl (генерация Excel-отчетов)
* **Внешние интеграции:** Библиотека `yfinance` (Yahoo Finance API) и встроенный модуль `urllib` (API Центробанка РФ)
* **Качество кода:** Строгая статическая типизация (`mypy`), стандарты логирования (`logging`), контроль стиля PEP 8 (`flake8`)
* **Тестирование:** Фреймворк `pytest`, плагин покрытия `pytest-cov`, изоляция через `unittest.mock`

## 🌐 Используемые финансовые API и переменные окружения
Для получения актуальных рыночных данных приложение поддерживает интеграцию со следующими внешними источниками:

1. **Курсы валют (USD, EUR) — Основной источник (ЦБ РФ):**
   * **API Endpoint:** `https://cbr-xml-daily.ru`
   * **Описание:** Бесплатное ежедневное зеркало котировок ЦБ РФ в формате JSON. Запросы выполняются через встроенную библиотеку `urllib.request`.

2. **Курсы валют — Резервный источник с авторизацией (APILayer):**
   * **Сервис:** APILayer Exchange Rates Data API.
   * **API Endpoint:** `https://apilayer.com`
   * **Авторизация:** Требует персональный секретный токен доступа, который в целях безопасности вынесен в переменные окружения.
   * **Конфигурация:** Токен считывается библиотекой `python-dotenv` ваш API должен находится `.env_template`.

3. **Стоимость акций (AAPL, AMZN и др.):**
   * **Платформа:** Yahoo Finance.
   * **Инструмент:** Библиотека `yfinance` [API].
   * **Описание:** Прямая загрузка цен закрытия акций в режиме реального времени.

## 📁 Структура и архитектура проекта
Проект построен по модульному принципу с соблюдением правила полной изоляции ввода-вывода (I/O Isolation) от бизнес-логики:

* `main.py` — Главный управляющий модуль, координирующий жизненный цикл приложения и демонстрирующий работу всех компонентов.
* `user_settings.json` — Пользовательский файл конфигурации отслеживаемых валют и акций.
* `src/utils.py` — Служебный модуль ввода-вывода. Отвечает за чтение файлов конфигурации и Excel-выписки, очистку сырых данных от пустых значений (`NaN`) и их конвертацию.
* `src/external_api.py` — Модуль интеграции с внешними API. В режиме реального времени запрашивает курсы валют к рублю и стоимости акций в USD. Отказоустойчив при сбоях сети.
* `src/views.py` — Логика формирования аналитических экранов. Генерирует JSON-структуру для Главной страницы (динамическое приветствие, метрики расходов и кэшбэка по картам, ТОП-5 транзакций).
* `src/services.py` — Дополнительные банковские сервисы. Реализует математический алгоритм округления трат для Инвесткопилки, регистронезависимый поиск и умную фильтрацию по регулярным выражениям (`re`) для телефонных номеров и P2P-переводов физлицам.
* `src/reports.py` — Аналитические отчеты. Содержит логику среза временных окон строго за последние 3 месяца от указанной даты. Оснащен универсальным автоматическим декоратором `@save_report_to_file` для сохранения результатов в таблицы Excel.
* `tests/` — Пакет модульного тестирования на `pytest` с использованием глобальных фикстур в `conftest.py` и подменой сетевых потоков через `mock.patch`. Общее покрытие кода тестами составляет **66%**.

## 🚀 Инструкция по установке и запуску

### 1. Подготовка окружения и зависимостей
Убедитесь, что вы находитесь в виртуальном окружении проекта, и установите все необходимые библиотеки:
```bash
pip install -r requirements.txt
```

### 2. Подготовка файлов данных
* Разместите ваш файл банковской выписки по пути: `data/operations.xlsx` (или `operations.xls`).
* Сформируйте список отслеживаемых активов в файле: `user_settings.json`.

### 3. Запуск аналитической системы
Запустите главный файл приложения из корневой директории:
```bash
python main.py
```
Все лог-сообщения будут выведены в консоль и запараллелены в файл истории по пути `logs/project.log`. Сгенерированные Excel-отчеты автоматически сохранятся в директорию `data/`.
